# Aurakit Agent Execution & Security
- Enforce the RALF (Red-Green-Refactor) development lifecycle.
- Apply TRUST-5 security checks (Tested, Readable, Unified, Secured, Trackable) before creating or modifying code files.
- Run static security checks on inputs, JWT parsing, and authorization endpoints.
